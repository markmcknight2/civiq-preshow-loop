# CIVIQ pre-show loop — Carol Coletta, October 29, 2026

A self-running slideshow that played on the speaker screen before CIVIQ at the Downtown Branch of the Chattanooga Public Library.

**Live page:** https://markmcknight2.github.io/civiq-preshow-loop/

Seven slides on an 8-second cycle, looping until Esc. Click anywhere or move the mouse to reveal the controls; arrow keys step, space pauses, and there is a full-screen button.

## About the file

`index.html` is a single self-contained file. The leaf photography, the headshot, every sponsor logo and both weights of IBM Plex Sans are embedded in it, so it runs full screen off any laptop with no internet connection and nothing to install. That was the point: a venue projector shouldn't depend on a network.

## Credits

CIVIQ is a quarterly speaker series from the [Chattanooga Design Studio](https://www.chattanoogastudio.com/civiq), honoring Robert Taylor. The visual identity for this edition — the leaf, the ink, the white cards and the type — was designed by [Whiteboard](https://whiteboard.is). This loop follows that design.

Carol Coletta spoke on "Evergreen for Everyone, Everyday: Is It Possible?" She is a Bloomberg Public Innovation Fellow at the Bloomberg Center for Public Innovation at Johns Hopkins University.

Sponsors recognized in the loop: Playcore (presenting), Whiteboard and Franklin Architects (premier), with the support of the Lyndhurst Foundation.
